# User Stories

### US-01 — Create Goal

**As a user, I want to enter my goal, deadline, and available time so that I can create a plan based on my actual situation.**

### US-02 — Decompose Goal

**As a user, I want my goal to be broken down into milestones and smaller tasks so that I can understand what I need to do step by step.**

### US-03 — Generate Schedule

**As a user, I want the system to create a schedule for my tasks based on my deadline and available time so that I know when to work on each task.**

### US-04 — Track Progress

**As a user, I want to mark tasks as completed and view my progress so that I can keep track of how much of my goal I have achieved.**

### US-05 — Get Daily Task Recommendation

**As a user, I want the system to recommend tasks for me to work on today so that I know what I should focus on next.**
